# v0.3.3.2 mixed supplier purchase orders — EXPERIMENTAL (#24 continuation)

Build Supplier Order now has four adjustable quantities (Universal Parts, Service Filters, Brake Kits, Diagnostic Supplies), one supplier, cost/capacity preview and explicit Place Purchase Order. LEFT removes one; RIGHT/ENTER adds one; controller D-pad left/right match, with semantic input arbitration. Quantities clamp 0–100, total 1–100. Fill Low-stock Cart prepares a draft; Clear Cart clears only that draft. Opening/editing/previewing never books stock or invoice. Draft quantities are session-only until submitted. Existing quick universal orders use the same submit path.

TryPlaceSupplierOrder clones validated quantities, checks total storage/free parcel slot and wholesale vehicle, computes sum of existing line-price calculations, assigns one identity/ETA and atomically saves before visual/waypoint work. Save failure restores all pending-order fields and manager savings; no order is silently lost. One parcel represents one combined shipment. Shared capacity and exactly one consolidated invoice apply at receipt. CommitSupplierDelivery applies all four inventory buckets and clears pending lines in the same atomic snapshot; failed receipt restores every bucket, provenance, invoice and original line array. Cancellation now saves clearing/refund before entity cleanup and rolls back on failure, including legacy prepaid refund.

Additive Save.ini [SupplierOrderV1]: Version=1, Line0..Line3 (0 by default), OrderTicks, Cost and Supplier identity stamp. Legacy absent/zero payload leaves pending single-item/prepaid order untouched. DeliveryKind stays the first item's legacy kind; DeliveryQuantity is aggregate units. Loader checks bounded counts, sum, identity, price, supplier and first kind before callbacks or save. Unsupported/malformed/stale cart payload fails closed and preserves the file for review. Completed/cancelled snapshots write zero lines and identity. Existing keys and unknown INI keys remain. No Settings.ini changes. Active delivery contents display the actual four lines.

Do not downgrade a pending mixed order to an older build: it cannot interpret line distribution. Finish/cancel first, or restore matching complete source/data backup with GTA closed. Do not delete cart/journal keys to bypass consistency checks. WHOLESALE still requires player warehouse pickup, vehicle transport/unload and manual stocking; manager modes apply only Local/Express. ETA uses existing active-game seconds, with no offline catch-up. Accepted quote ledger, sales, wages and pallet geometry remain unchanged.

Changed exact methods and before/after are in focused 03-source.diff; new helpers cover total/cost, placement, load/write, shared inventory application, draft editing, low-stock fill, order contents and transactional cancellation. Before: BuyInventory stored one kind/quantity and unchecked Save. After: TryPlaceSupplierOrder saves four cloned lines with rollback, and terminal receipt/cancellation share atomic business persistence.
