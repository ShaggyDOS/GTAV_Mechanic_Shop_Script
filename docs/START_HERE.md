# Start Here

This project is a GTA V mod script workspace for the GlassHeroes Business system.

## Quick Start

1. Review the repository structure in `README.md`
2. Add your source code to `scripts/`
3. Copy or customize settings in `config/Settings.ini.example`
4. Review the project roadmap and release notes in `docs/`
5. Test locally in your GTA V mod setup

## Important

- Keep actual source files tracked in Git.
- Ignore generated build files and local test data via `.gitignore`.
- Use `install/` for packaged or deployable versions of the mod when you are ready to distribute them.

## Recommended Workflow

- Work on source files first.
- Keep backups and validation artifacts separate from source.
- Only add compiled or packaged outputs to the repo when they are intentional release files.
